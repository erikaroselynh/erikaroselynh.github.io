# Erika Roselyn Husen — Portfolio ("my little internet")

Plain HTML / CSS / JavaScript. No build step, no dependencies, no backend.

## Run locally (macOS + VS Code)
1. Unzip this folder and open it in VS Code (File > Open Folder).
2. Install the "Live Server" extension (Ritwick Dey), right-click `index.html` > "Open with Live Server".
   Or just double-click `index.html` to open it in your browser, or run `python3 -m http.server 8000` in the folder and visit http://localhost:8000.

## Where to edit
- All project content lives in the `PROJECTS` array near the bottom of `index.html`.
- Screenshots live in `assets/`. Keep file names the same, or update the `src` paths.
- Replace the "PLACEHOLDER" boxes (type `placeholder`) with real visuals by switching them to a `gallery` section.
